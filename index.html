Kết nối GitHub

Dùng repo private để lưu câu hỏi. Trang GitHub Pages chỉ chứa mã giao diện, không chứa token hay dữ liệu riêng tư.

Token chỉ lưu tạm trong RAM của tab này, không ghi vào GitHub Pages, URL hay localStorage. Token phải có quyền Contents: Read đối với repo dữ liệu.
Không thể kết nối?

Bạn vẫn có thể xem ngân hàng bằng file JSON đã xuất từ tiện ích hoặc file trên GitHub.
