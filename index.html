CONNECT YOUR REPOSITORY

Kết nối GitHub

Dùng repo private để lưu câu hỏi. Trang GitHub Pages chỉ chứa mã giao diện, không chứa token hay dữ liệu riêng tư.

Tên repository được tự lưu. Mặc định token chỉ được giữ trong phiên trình duyệt để không phải nhập lại khi tải trang. Nếu bật “Ghi nhớ token lâu dài”, token sẽ được lưu vào bộ nhớ trình duyệt; các script chạy cùng website có thể truy cập được. Không dùng trên máy chung. Xem dữ liệu cần Contents: Read; đẩy đáp án cần Contents: Read and write cho repo dữ liệu.
Không thể kết nối?

Có thể mở file JSON từ tiện ích. Bản vừa mở sẽ tự lưu để lần sau vào web vẫn xem được trên thiết bị này.
