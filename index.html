Bảng điểm học kỳ

Tự động lưu sau mỗi thay đổi. Có thể cuộn ngang bảng trên điện thoại.

Tổng hai hệ số phải bằng 1. Điểm hợp lệ từ 0 đến 10.

Công thức theo ảnh: Điểm tổng = thành phần × hệ số + thi × hệ số; GPA môn hệ 4 = tổng × 0,4; GPA học kỳ = ∑(điểm môn × tín chỉ) / ∑ tín chỉ. Đây là cách quy đổi tuyến tính theo mẫu, không thay thế quy chế xếp loại hệ 4 chính thức của trường.

CONNECT YOUR REPOSITORY

Kết nối GitHub

Dùng repo private để lưu câu hỏi. Trang GitHub Pages chỉ chứa mã giao diện, không chứa token hay dữ liệu riêng tư.

Tên repository được tự lưu. Mặc định token chỉ được giữ trong phiên trình duyệt để không phải nhập lại khi tải trang. Nếu bật “Ghi nhớ token lâu dài”, token sẽ được lưu vào bộ nhớ trình duyệt; các script chạy cùng website có thể truy cập được. Không dùng trên máy chung. Token chỉ cần Contents: Read với repo dữ liệu.
Không thể kết nối?

Có thể mở file JSON từ tiện ích. Bản vừa mở sẽ tự lưu để lần sau vào web vẫn xem được trên thiết bị này.
